# Analisis-de-datos_TP_UTN
Programa en C# para analizar la mejor opción de inversión.

Desarrollar un programa que permita analizar y determinar la mejor opción para invertir un capital de $850,000 en plazos fijos ofrecidos por el Banco Provincia, Banco Nación y Banco Hipotecario. 

Para ello: 
1. Solicitar al usuario que ingrese los valores históricos de los plazos fijos anuales de los últimos 3 años para cada banco.
2. Calcular el promedio de las tasas anuales de cada banco.
3. Evaluar la conveniencia de invertir el capital considerando las siguientes modalidades:
   
   o Inversión por **un año completo** con la tasa anual promedio.
   o Inversión por **trimestres**, calculando el rendimiento y reinvirtiendo el capital ganado al finalizar cada trimestre.
   o Inversión por **meses**, calculando el rendimiento y reinvirtiendo el capital ganado al finalizar cada mes.

   El programa deberá mostrar en pantalla: Los rendimientos obtenidos en cada modalidad para cada banco. La opción más rentable y el banco recomendado para realizar la inversión.
